# Audiobook Excerpt Campaign

## Source Handling

Preserve lossless masters unchanged. Copy selected ranges into a campaign workspace and export social copies as broadly compatible MP3 files. Record codec, sample rate, channels, bitrate, loudness treatment, and exact duration.

Run `../scripts/audio_inventory.py` before excerpt selection.

## Excerpt Selection

Choose excerpts that deliver a complete lesson without requiring the rest of the chapter. Favor language with a clear tension, insight, and audience question.

Score each candidate on:

| Criterion | Question |
|---|---|
| Standalone value | Does it make sense without setup? |
| Voice authority | Does the author sound distinctive and credible? |
| Hook strength | Does the first sentence stop the scroll? |
| Thematic diversity | Does it add a new campaign pillar? |
| Conversion relevance | Does it create curiosity for the complete work? |
| Sensitivity | Can it be framed responsibly in a short post? |

For every selected clip, record the source filename, start and end timestamps, transcript, exported filename, hook, theme, role in the sequence, and sensitivity note.

## Seven-Day Narrative Default

Use this progression when the book supports it:

| Day | Function | Example Theme |
|---:|---|---|
| 1 | Immediate personal practice | Mindset or mantra |
| 2 | Practical strategy | Audience or business |
| 3 | Emotional identification | Belief or confidence |
| 4 | Social-impact depth | Healing or accountability |
| 5 | Cultural thesis | Originality or contribution |
| 6 | Self-mastery | Inner critic or discipline |
| 7 | Leadership close | Responsibility or legacy |

Reorder the sequence when the manuscript has a stronger internal arc.

## Audio Production

Use short fades and consistent loudness. Preserve the speaker’s natural pacing and do not stretch, synthesize, or rewrite the original performance. Keep campaign exports separate from customer audiobook files.

Recommended social export:

| Field | Default |
|---|---|
| Format | MP3 |
| Sample rate | Match source or 44.1 kHz |
| Channels | Preserve stereo when present |
| Bitrate | 192 kbps or better |
| Clip length | Prefer 15–45 seconds |

## Reel Standard

Create one 9:16 Reel per excerpt. Use the original narration as the primary sound unless the user requests music. Add accurate burned-in captions, one kinetic hook, an animated waveform or equivalent audio visualization, official product art, and a three-second CTA card.

Recommended output:

| Field | Default |
|---|---|
| Frame size | 1080 × 1920 |
| Frame rate | 30 fps |
| Video | H.264 |
| Audio | AAC |
| CTA duration | 3 seconds |

Do not let captions cover critical product text or faces. Use high contrast and mobile-safe margins.

## Feed Cover Standard

Create one standalone cover per post. Maintain a consistent layout, palette, product treatment, day number, and CTA. Use the official cover as a fidelity reference. Keep headline copy short enough for mobile reading.

## Platform Copy

Write a distinct caption for each platform. Instagram and Facebook can use the enabled ManyChat comment keyword. Threads, X, Bluesky, and TikTok should use direct storefront or link-in-bio language unless their own automation is configured.

Every daily caption should contain:

1. A thesis line.
2. A short expansion of the excerpt’s lesson.
3. One audience question.
4. One conversion action.
5. Platform-appropriate tags.

## Sensitivity

For trauma, mental-health, violence, or grief material, use compassionate framing and avoid diagnosis or implied clinical treatment. Encourage qualified support when appropriate. Do not sensationalize a vulnerable excerpt for engagement.

## Validation

Check the final set for:

| Check | Requirement |
|---|---|
| Clip count | Matches campaign day count |
| Source mapping | Every clip has timecodes and transcript |
| Audio integrity | Files decode and durations are plausible |
| Reel resolution | 9:16 and mobile-ready |
| Captions | Accurate and readable |
| Feed covers | One standalone image per day |
| CTA | Matches the active conversion system |
| Platform promises | Do not claim automation where none exists |
