# Asset Registry

This reference has been superseded by `master-asset-registry.md`, which now serves as the primary control sheet for Lord Judah's video and music-video asset selection system.

Use `master-asset-registry.md` whenever a task requires choosing the correct **avatar**, **voice**, **photo**, **generated identity preset**, **scene preset**, **performance mode**, or **approval state**.

## When to Use This File

Use this file only as a lightweight bridge for older workflows that still refer to an **asset registry** by name. In those cases, treat the master registry as the source of truth and update that file instead of rebuilding mappings here.

## Legacy Mapping Note

The older simplified tables are no longer the recommended place for maintenance because they do not capture enough detail about **approval status**, **default categories**, **generated identity presets**, **music-video performance presets**, or **task-memory updates**.

For all future upkeep, maintain the richer system in the master registry.
