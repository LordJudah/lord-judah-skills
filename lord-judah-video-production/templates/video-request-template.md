# Video Request Template

Use this template to make future video requests precise and repeatable.

| Field | Fill in |
|---|---|
| Mode | Avatar video / image-to-video / uploaded-image-to-video / hybrid |
| Avatar or image | Name the exact avatar, uploaded file, or image set |
| Voice | Name the exact voice or say to use the default Lord Judah voice |
| Aspect ratio | 9:16 / 16:9 / 1:1 |
| Duration | Desired length |
| Scene | Describe the environment in one sentence |
| Motion | Describe the desired motion in one sentence |
| Script or audio | Final line, script, or uploaded audio |
| Style notes | Cinematic, realistic, promo, reflective, educational, etc. |
