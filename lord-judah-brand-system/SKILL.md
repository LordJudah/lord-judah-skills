# Lord Judah Brand System

## Overview

Use this skill whenever a task involves **Lord Judah brand expression, short-form video creation, creative direction, NotebookLM knowledge preparation, or reusable asset generation**. This skill packages the durable outputs extracted from prior work into a single operating system so future tasks can stay aligned with Lord Judah’s voice, visual identity, content structure, and scaling strategy.

The main purpose of this skill is to prevent drift. It helps future work stay recognizably **Lord Judah** rather than becoming generic, trend-dependent, or stylistically inconsistent.

## When to Use This Skill

Use this skill when the task involves any of the following:

| Situation | Use this skill? | What to read |
|---|---|---|
| Writing new Lord Judah scripts or narration | Yes | `references/brand-voice-bible.md` and `references/prompt-library.md` |
| Building short-form video workflows or production plans | Yes | `references/short-form-sop.md` |
| Recreating or extending *The Science of Nostalgia* format | Yes | `references/science-of-nostalgia-production-template.md` |
| Creating NotebookLM-ready brand knowledge | Yes | `references/notebooklm-knowledge-source.md` |
| Generating captions, titles, hooks, or scene prompts | Yes | `references/prompt-library.md` |
| General non-Lord Judah creative work | Usually no | Only use if the user explicitly wants Lord Judah alignment |

## Core Operating Rule

Treat Lord Judah as a combined **artist, educator, philosopher, creative director, cultural strategist, and innovator**. Outputs should preserve all of those dimensions together. Do not flatten the voice into generic creator language.

## Quality Standard

Before delivering any output created with this skill, check it against the following standard.

| Check | Pass condition |
|---|---|
| Voice authenticity | Sounds unmistakably like Lord Judah |
| Cultural integrity | Honors hip-hop and community with intelligence |
| Production logic | Can actually be executed, not just admired |
| Visual coherence | Can translate into premium cinematic scenes |
| Scalability | Fits a reusable system rather than a one-off improvisation |

## Anti-Patterns

Avoid the following when using this skill.

| Anti-pattern | Why it fails |
|---|---|
| Generic influencer voice | Weakens brand distinction |
| Empty motivation language | Reduces depth and trust |
| Overhyped tech worship | Conflicts with the principle that AI enhances, not replaces, vision |
| Shallow trend-chasing | Breaks the long-term brand system |
| Overcomplication without execution value | Makes scaling harder |
