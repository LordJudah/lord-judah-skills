# Lord Judah Short-Form Video SOP

## Purpose

This document defines the **standard operating procedure** for Lord Judah’s repeatable short-form video system. It is designed to turn the creative process into a reliable production framework that can be repeated, scaled, delegated, and improved over time without diluting the brand.

This SOP should be used whenever creating short-form videos intended for Instagram Reels, TikTok, YouTube Shorts, and related platforms. It assumes that each video is both a piece of content and a unit of intellectual property.

## Strategic Objective

The objective of this system is to produce short-form videos that are simultaneously:

| Objective | Meaning |
|---|---|
| **Brand-building** | Reinforce Lord Judah as artist, educator, philosopher, and innovator |
| **Audience-growing** | Increase engagement, retention, saves, shares, and follows |
| **Educational** | Teach ideas tied to hip-hop, culture, healing, identity, and technology |
| **Scalable** | Allow repeatable production across multiple daily outputs |
| **Catalog-driven** | Build a reusable library of scripts, prompts, music ideas, scenes, and IP |

The system is not optimized for random posting. It is optimized for **consistent, high-value, concept-led output**.

## Production Model

This workflow operates best as a **tiered content system** rather than a single uniform production style.

| Tier | Daily use | Typical role |
|---|---|---|
| **Tier 1: Hero pieces** | 1 to 2 per cycle | Signature cinematic thought-leadership videos |
| **Tier 2: Standard pieces** | Several per cycle | Strong educational and brand-building videos using templates |
| **Tier 3: Derivative assets** | Multiple per cycle | Shorter clips, hooks, quote cuts, and micro-content pulled from larger concepts |

The same concept may generate assets across all three tiers.

## Workflow Overview

Every project should move through the following phases in order.

| Phase | Output |
|---|---|
| **1. Concept selection** | Clear thesis and content lane |
| **2. Script development** | Scene-based narration draft |
| **3. Visual planning** | Scene map and prompt set |
| **4. Audio generation** | Voiceover files and music direction |
| **5. Visual generation** | Direct video scenes or image-first animated scenes |
| **6. Editorial assembly** | Timed vertical master edit |
| **7. Packaging** | Titles, captions, hashtags, descriptions |
| **8. Export and distribution** | Platform-ready deliverables |
| **9. Archive and monetization tracking** | Organized storage and rights management |

## Phase 1: Concept Selection

Every video begins with a **clear conceptual thesis**. The topic should come from an approved content lane so that the output remains coherent with the larger system.

| Approved series lane | Example themes |
|---|---|
| **Science of Sound** | Sampling, memory, dopamine, rhythm, emotion |
| **Hip-Hop Philosophy** | Identity, discipline, truth, purpose, resilience |
| **AI and the Artist** | Future literacy, authorship, tools, ethics, augmentation |
| **Street Wisdom / Higher Wisdom** | Healing, mindfulness, transformation, consciousness |
| **True He(ART) Academy Lessons** | Youth empowerment, pedagogy, arts education, SEL |
| **Micro Storytelling** | Short reflective narratives with a lesson or turn |

### Concept Selection Rule

Choose ideas that satisfy at least three conditions.

| Requirement | Question |
|---|---|
| **Brand fit** | Does this sound like Lord Judah? |
| **Depth** | Does it contain a real idea, not just a trend? |
| **Visual potential** | Can it become 5 to 7 cinematic scenes? |
| **Narration strength** | Will it sound powerful aloud? |
| **Packaging potential** | Can it generate strong hooks and captions? |

If a concept is trendy but shallow, it should be rejected or reframed.

## Phase 2: Script Development

Once the concept is approved, write a **scene-based spoken-word script**. The preferred structure is 5 scenes, though 5 to 7 scenes may be used depending on runtime.

| Scene function | Purpose |
|---|---|
| **1. Hook / thesis** | Stop the scroll and introduce the big claim |
| **2. Explanation** | Add science, psychology, philosophy, or history |
| **3. Community grounding** | Connect to youth, culture, healing, or lived experience |
| **4. Future bridge** | Extend toward innovation, AI, or future-building |
| **5. Resolution / CTA** | Close with warmth, unity, and invitation |

### Script Standards

| Standard | Requirement |
|---|---|
| **Tone** | Calm, authoritative, warm |
| **Cadence** | Spoken-word friendly |
| **Clarity** | Intellectually strong but accessible |
| **Depth** | Must reframe the topic rather than merely describe it |
| **Length** | Usually 60 to 90 seconds total |

The script should be split into separate scene segments because voice generation and editing work best on a scene-by-scene basis.

## Phase 3: Visual Planning

After the script is drafted, translate it into a **scene map**. Each scene should have a title, visual purpose, prompt direction, and motion concept.

| Scene-planning field | Requirement |
|---|---|
| **Scene title** | Memorable working label |
| **Narrative purpose** | Why the scene exists |
| **Environment** | Where it takes place |
| **Lord Judah role** | What he is doing in frame |
| **Visual symbols** | Objects, overlays, lighting, motifs |
| **Motion style** | Push-in, orbit, drift, track, pulse, etc. |
| **Color direction** | Warm gold, cool blue, soulful ambers, etc. |

The visual system should consistently place **Lord Judah as the anchor figure** in the scene unless the concept explicitly requires a different approach.

## Phase 4: Audio Generation

### Voiceover Workflow

Each scene’s narration should be rendered as a separate file through the Lord Judah voice profile.

| Audio step | Requirement |
|---|---|
| **1** | Generate one narration file per scene |
| **2** | Name files by project and scene number |
| **3** | Review pacing and pronunciation |
| **4** | Regenerate any scene with weak emphasis or incorrect cadence |

### Music Workflow

Music should be selected or generated to support the narration rather than compete with it.

| Music rule | Guidance |
|---|---|
| **Tempo** | Usually 90 to 95 BPM for this lane |
| **Foundation** | Cinematic boom-bap, dusty texture, soulful warmth |
| **Space** | Leave room for voiceover |
| **Mood** | Intelligent, reflective, future-soul, grounded |

## Phase 5: Visual Generation

The system supports two branches.

| Branch | Use case |
|---|---|
| **Direct video generation** | Faster scene production with built-in motion |
| **Image-first animation** | Better composition control and more consistent scene identity |

### Branch A: Direct Video Generation

Generate portrait-style scenes directly from scene prompts. Ensure the prompts specify cinematic framing, motion style, lighting, and Lord Judah’s role in frame.

### Branch B: Image-First Animation

Generate still images for each scene first, then animate them using a motion model such as Kling.

| Image-first step | Requirement |
|---|---|
| **1** | Generate the still images |
| **2** | Save and label by scene number |
| **3** | Match each image to a scene-specific motion prompt |
| **4** | Animate with subtle cinematic motion |
| **5** | Export each animated scene for editing |

The image-first branch should be preferred when the initial direct video output lacks control, consistency, or visual precision.

## Phase 6: Editorial Assembly

Once narration, music, and scene assets are ready, assemble the vertical edit.

| Editorial step | Action |
|---|---|
| **1** | Create the 9:16 sequence |
| **2** | Import scene assets in order |
| **3** | Detach and remove any unwanted scene audio |
| **4** | Insert the separate voiceover files |
| **5** | Retime scenes to fit the narration |
| **6** | Enhance narration with the standard vocal chain |
| **7** | Add music and mix it under the narration |
| **8** | Review pacing, transitions, and emotional arc |
| **9** | Export the vertical master |

### Editorial Rule

Do not force the narration to chase the visuals. The visuals should be shaped to serve the spoken message. The narration is the spine of the piece.

## Phase 7: Packaging

Each finished video must be packaged differently for each platform.

| Platform | Packaging requirement |
|---|---|
| **Instagram** | Reflective caption with emotional and cultural resonance |
| **TikTok** | Punchy, compressed, hook-first caption |
| **YouTube** | Search-friendly title and expanded description |

Every asset should also receive a working title, caption file, and hashtag set.

## Phase 8: Export and Distribution

| Output | Requirement |
|---|---|
| **Master video** | Final 9:16 file |
| **Platform copies** | Ready for Instagram, TikTok, and YouTube Shorts |
| **Caption copy** | Saved in an associated text or markdown file |
| **Thumbnail or cover note** | If needed for YouTube or reposting |

Distribution should follow a consistent release order so the process remains scalable and trackable.

## Phase 9: Archive and Monetization Tracking

Every project should be archived as a reusable content asset.

| Archive item | What to save |
|---|---|
| **Script** | Final voiceover text |
| **Prompts** | Scene prompts, motion prompts, music prompts |
| **Voice files** | One per scene |
| **Scene assets** | Source videos or animated clips |
| **Music file** | Final or working instrumental |
| **Final export** | Master vertical video |
| **Captions** | Platform-ready copy |
| **Metadata** | Date, title, series lane, performance notes |

When relevant, the work should also be tracked for registration, cataloging, and monetization follow-through.

## Naming Convention

Use a consistent naming structure to prevent confusion and support scale.

| Asset type | Example |
|---|---|
| **Project folder** | 2026-04-science-of-nostalgia |
| **Scene voiceover** | science_of_nostalgia_scene_01.wav |
| **Scene video** | science_of_nostalgia_scene_01.mp4 |
| **Animated image clip** | science_of_nostalgia_scene_01_kling.mp4 |
| **Music file** | science_of_nostalgia_bgm_v1.wav |
| **Master export** | science_of_nostalgia_master_9x16_v1.mp4 |
| **Caption file** | science_of_nostalgia_platform_captions.md |

## Quality-Control Checklist

Before publishing, every piece should be reviewed against the following standards.

| Check | Pass condition |
|---|---|
| **Voice authenticity** | Sounds unmistakably like Lord Judah |
| **Brand integrity** | Aligns with culture, intelligence, and mission |
| **Visual coherence** | Scene flow feels consistent and intentional |
| **Narration clarity** | Voice is intelligible and emotionally grounded |
| **Music balance** | Instrumental supports rather than competes |
| **Platform readiness** | Titles, captions, and format are complete |
| **Archive readiness** | All key assets are saved and labeled |

## Scaling Guidance

The SOP should support growth toward higher daily output by reducing reinvention.

| Scaling method | Purpose |
|---|---|
| **Use recurring series lanes** | Speeds up ideation |
| **Batch script generation** | Produces multiple concepts at once |
| **Reuse approved prompt structures** | Improves consistency |
| **Maintain a master asset registry** | Reduces confusion around recurring assets |
| **Separate hero and derivative content** | Makes higher publishing volume realistic |

## Final Rule

This system should always protect the relationship between **message, culture, and execution**. Speed matters, but it should never come at the cost of authenticity, depth, or recognizability.

The goal is not to mass-produce noise. The goal is to **systematize meaningful content without losing soul**.
