# Lord Judah Prompt Library

## Purpose

This prompt library centralizes the **approved prompt patterns, reusable structures, and generation formulas** for Lord Judah’s short-form video system. It is meant to reduce reinvention, improve consistency, and help NotebookLM or any production assistant move faster while preserving the brand.

This file should be treated as a working library. Prompts can evolve, but they should always remain aligned with the Brand Voice Bible, the Short-Form SOP, and the larger Lord Judah creative system.

## How to Use This Library

The prompts in this file are not all meant to be copied word for word forever. They are designed as **reusable templates**. The most effective workflow is to preserve the structure, tone, and logic while swapping the topic, visual symbols, or references as needed.

| Prompt category | Best use |
|---|---|
| **Idea prompts** | Generate strong concepts within approved content lanes |
| **Script prompts** | Produce scene-based narration in Lord Judah voice |
| **Scene prompts** | Create cinematic visual direction for AI image or video tools |
| **Motion prompts** | Animate still images with restrained cinematic life |
| **Music prompts** | Generate background instrumentals that support narration |
| **Caption prompts** | Package content differently for each platform |
| **Title prompts** | Create hooks and search-friendly packaging |

## Section I: Idea Generation Prompts

These prompts are for generating new content ideas while staying inside the Lord Judah universe.

### C. Hook-Only Prompt

> Generate 25 short-form opening hooks for Lord Judah that sound bold, intelligent, and scroll-stopping. The hooks should reframe familiar cultural ideas in unexpected ways and be suitable for spoken-word educational videos.

## Section II: Script Generation Prompts

These prompts produce the actual narration structure.

### A. Standard 5-Scene Script Prompt

> Write a five-scene short-form narration script for Lord Judah in a calm, authoritative, warm voice. The subject is: [TOPIC]. The script should sound like spoken-word cultural scholarship and should follow this structure: Scene 1 opens with a bold thesis, Scene 2 explains the deeper science, psychology, philosophy, or history, Scene 3 grounds the idea in youth, community, healing, or identity, Scene 4 bridges the concept into innovation, AI, or future-building, and Scene 5 ends with warmth, unity, and a community-centered call to action. Keep it intellectually rich but accessible. Make each scene suitable for separate voiceover generation.

### B. Alternate 7-Scene Script Prompt

> Write a seven-scene short-form educational script for Lord Judah on [TOPIC]. The tone should be intelligent, reflective, and culturally rooted. Each scene should be concise enough for separate voice generation, and the full script should feel cinematic, emotionally layered, and aligned with Lord Judah’s role as artist, educator, philosopher, and futurist.

### C. Tightened Script Revision Prompt

> Rewrite this Lord Judah script for stronger spoken-word cadence, clearer emotional arc, and sharper phrasing without losing depth. Keep the tone calm, powerful, and grounded. Improve its pacing for short-form narration while preserving the main thesis.

## Section III: Scene Architecture Prompt

This prompt helps translate a script into a visual map.

> Turn this Lord Judah short-form script into a scene architecture table. For each scene, provide: scene title, narrative purpose, emotional role, environment, Lord Judah’s action in frame, key symbols or objects, color direction, and recommended camera movement. The scenes must be cinematic, symbolic, and suitable for vertical AI-generated visuals.

## Section VI: Motion Prompt Templates for Kling or Similar Tools
