# BMI Registration Intake Checklist

Use this checklist when preparing to register a new work through BMI.

## Minimum information needed to start a standard registration

| Field | Required? | Default / expected value for Lord Judah workflow |
|---|---|---|
| Title | Yes | User provides this each time |
| Duration | Yes | User provides this each time in minutes/seconds |
| Language | Usually no | English |
| Work type | Usually no | All Other Genres |
| Work content | Usually no | Music and Lyrics |
| Arrangement / translation | Usually no | No |
| Contains samples or medleys | Usually no | No |
| Artists listed in BMI registration | Usually no | No |
| Recordings listed in BMI registration | Usually no | No |
| Created for Film / TV / Theater / Music Library | Usually no | No |
| Additional related information comments | Usually no | Leave blank |

## Ask the user before proceeding if any of these are true

1. The work includes **samples**, a **medley**, or a **translation**.
2. There are **co-writers**, additional publishers, or split changes.
3. The work should list **artists** or **recordings** in BMI.
4. The work was created for **film, TV, theater, or a music library**.
5. The title has an alternate title or special formatting that must be preserved.
6. The user wants any special comments in **Additional Related Information**.

## Submission safeguards

1. If BMI requires login, open the BMI page and ask the user to take over if needed.
2. Before final submission, summarize the work title, duration, and key assumptions.
3. Ask for explicit confirmation before clicking **Submit** because submission is a sensitive browser action.
4. Save the resulting confirmation details after submission.
