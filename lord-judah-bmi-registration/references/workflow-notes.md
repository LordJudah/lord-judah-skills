## Observed workflow

The PDF documents a BMI online work-registration flow for a new original work.

| Step | Observed detail |
|---|---|
| 1 | Start from BMI online services / login page. |
| 2 | Open a new work registration. |
| 3 | In **Step 2 of 5: Other Works**, select **No** for public domain arrangement / foreign lyric version when the work is a new original work. |
| 4 | In the same step, select **No** for samples or medleys for the example shown. |
| 5 | In **Step 3 of 5: Publishers & Writers**, add the publisher using a previous publisher entry. |
| 6 | The example publisher is **JUDAH BLESS PUBLISHING** with BMI affiliation and IP Name # **00747359899**. |

| 8 | Add the writer using a previous writer entry. |

## Operational insight for the future skill

The workflow suggests an important acceleration strategy: as soon as the user knows the **title** and **duration**, a registration draft can likely be completed quickly using the fixed writer/publisher data and the observed defaults, while content production continues in parallel.
