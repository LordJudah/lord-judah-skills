# Lord Judah Skills Library

The complete agent skills library for **Judah Bless Ent** and **True He(ART) Academy** — 78 skills in one repository, ready to import into **Manus** and **Cue**.

> **Layout:** one directory per skill at the repository root, each containing a `SKILL.md` with YAML frontmatter plus its own `scripts/`, `references/`, `assets/`, and `templates/`.

## Import into Manus or Cue

Manus and Cue import **one skill per URL**, so use the **per-skill folder URL** — not the repository root.

1. Open the **Skills** tab → **+ Add** → **Import from GitHub**
2. Paste a skill's folder URL:

```
https://github.com/LordJudah/lord-judah-skills/tree/main/lord-judah-brand-system
```

3. Click **Import**. Repeat for each skill you want.

> Pasting the repository root (`https://github.com/LordJudah/lord-judah-skills`) fails with **"SKILL.md not found in zip file"** — the importer reads the root of the archive, and there is no `SKILL.md` at the root of a multi-skill repo. Always use the folder URL ending in the skill name.

**Bulk list:** [`import-urls.txt`](./import-urls.txt) (one URL per line) and [`import-urls.csv`](./import-urls.csv) contain every import URL. The tables below also link each one directly.

## Clone instead (for tools that read a skills directory)

```bash
git clone https://github.com/LordJudah/lord-judah-skills.git ~/.cues/skills
```

This works for clients that scan a folder for skill subdirectories. It does **not** work with the single-skill GitHub importer.

## Machine-readable index

[`skills.json`](./skills.json) lists every skill with its directory, description, source (`user-created` or `built-in`), file count, size, and `importUrl`.
