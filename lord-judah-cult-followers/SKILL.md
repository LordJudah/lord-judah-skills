# Lord Judah Cult Followers — Meta Ads Growth Strategy

## What This Does

Runs a $5/day Meta Engagement Ad on a Lord Judah Reel, then builds a **Lookalike Audience** from people who watched 95%+ of it. Each campaign compounds the audience quality — followers become self-selecting, highly engaged fans.

## Lord Judah Account Info

| Field | Value |
|---|---|
| Instagram Handle | @lordjudah |
| Meta Ads Manager | Access via business.facebook.com |
| Recommended Daily Budget | $5–$10/day per song |
| Ad Duration | 7–14 days per release post |

## Step-by-Step Execution

### Step 1 — Create the Campaign

1. Go to **Meta Ads Manager** → business.facebook.com/adsmanager
2. Click **"+ Create"**
3. Select objective: **Engagement**
4. Click **Continue**
5. Name the campaign: `LJ - [Song Title] - Engagement - [Date]`
6. Set **daily budget**: $5 minimum (recommend $5–$10)
7. Click **Next**

### Step 2 — Configure the Ad Set

1. **Conversion location:** Change to **"On your ad"**
2. **Engagement type:** Change to **"Video views"**
3. **Performance goal:** Set to **"Maximize engagement with a post"**
4. **Schedule:** Start = release date, End = 7–14 days later
5. **Audience targeting:**
   - Age: 18–45
   - Gender: All
   - Location: United States (expand worldwide after first campaign)
   - Interests: Hip hop, conscious rap, music, Kendrick Lamar, J. Cole, Nas
6. Click **Next**

### Step 3 — Set Placements (CRITICAL — Follow Exactly)

1. Select **"Manual placements"** (NOT Advantage+)
2. **Turn OFF:** Facebook (all), Audience Network (all), Threads (all)
3. **Keep ON — Instagram only:**
   - Instagram Feed ✅
   - Instagram Reels ✅
   - Everything else ❌
4. Click **Next**

### Step 4 — Select the Ad (Existing Post)

1. Under Ad setup → select **"Use existing post"**
2. Click **"Select Post"** → choose **@lordjudah**
3. Select the **release day Reel** for the song being promoted
4. Preview → confirm correct post → **Publish**

**Song → Post mapping:**

| Song | Release Date |
|---|---|
| Blessed and Grateful | Jul 26, 2026 |
| Just Walking With My Dog | Jul 30, 2026 |
| Navigating The Way | Aug 3, 2026 |
| Battle For Earth | Aug 6, 2026 |

### Step 5 — Build the Retargeting Audience (After 3–5 Days)

**Create Custom Audience:**
1. Audiences tab → **"+ Create Audience"** → **"Custom Audience"**
2. Source: **"Video"**
3. Engagement: **"People who have watched at least 95% of your video"**
4. Select the specific Reel used in the ad
5. Lookback window: **30 days**
6. Name: `LJ - [Song Title] - 95% Viewers` → Save

**Create Lookalike Audience:**
1. **"+ Create Audience"** → **"Lookalike Audience"**
2. Source: the 95% viewers Custom Audience above
3. Location: United States (or worldwide)
4. Size: **1%** (most similar)
5. Name: `LJ - [Song Title] - Lookalike 1%` → Save

**Launch Lookalike Campaign:**
- Duplicate the original campaign
- Replace audience with the new Lookalike
- Run 7–14 more days

## Compounding Strategy

```
Song 1 Reel → 95% Viewers → Lookalike A
Song 2 Reel → 95% Viewers → Lookalike B
Combine A + B → Broader Lookalike for Album Campaign
```

After 4 songs, combine all Lookalikes for a high-intent album release audience.
