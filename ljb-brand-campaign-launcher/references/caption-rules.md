# Caption Rules — LJB Brand Campaign Launcher

## Brand Voice

Lord Judah's caption voice is: **poetic, layered, conscious, direct, and empowering**. Every caption should feel like a transmission — not a promotion. Avoid generic marketing language. Write as Lord Judah speaking directly to his community.

Tone markers:
- Philosophical and reflective ("What is legacy?")
- Call to action through invitation, not demand ("Join us." / "Tag a fellow visionary.")
- Spiritual + futuristic blend ("The frequency is set.")
- Questions that spark conversation ("How do you see AI shaping the future of hip-hop?")

## Platform Rules

### Instagram

| Rule | Value |
|---|---|
| Max hashtags | **5** (Blotato enforces — will error if exceeded) |
| Practical max characters | ~2,200 |
| Hashtag placement | End of caption |
| Tone | Full poetic copy, layered, brand-rich |
| CTA | "Link in bio" or direct URL |

**Instagram caption structure:**
```
[2–4 lines of poetic/brand copy]

[1 engagement question or CTA]

#Hashtag1 #Hashtag2 #Hashtag3 #Hashtag4 #Hashtag5
```

### Threads

| Rule | Value |
|---|---|
| Max characters | **500** (Blotato enforces — will error if exceeded) |
| Hashtags | 1–3 max (no hard limit but keep minimal) |
| Tone | Punchy, direct, conversational — distilled version of IG caption |
| CTA | Include URL directly in text (no "link in bio") |

**Threads caption structure:**
```
[1–2 punchy lines that capture the day's essence]

[Optional: URL or engagement question]

#Hashtag1 #Hashtag2
```
