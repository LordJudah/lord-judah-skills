# LJB Caption Framework

## Brand Voice Principles

- **Poetic but grounded** — metaphors rooted in real experience, not abstract fluff
- **Empowering, never boastful** — strength through wisdom, not ego
- **Cultural and spiritual depth** — every caption should carry a layer of meaning
- **True He(ART) energy** — healing, growth, transformation woven in naturally
- **Conscious hip-hop cadence** — reads like bars, not marketing copy

## Caption Structure (Instagram / Threads)

```
[2–3 line poetic statement — the hook]
[1 line of depth or contrast]
[Vibe word or short phrase] [emoji]

[Collection tag — e.g. "Tokyo Tiger Collection — TT-09"]
[Brand tag — "Judah Bless Ent"]

[3–5 hashtags]
```

## Caption Structure (Twitter/X)

```
[2–3 punchy lines — no filler]
[Emoji]
[Collection code] · @judahblessent
```

## Caption Structure (TikTok)

Single flowing paragraph. No line breaks. Same hashtags. Keep it conversational and energetic.

## Caption Tone by Vibe Category

| Vibe | Tone | Example opener |
|------|------|----------------|
| Sacred / Spiritual | Reverent, meditative | "The koi doesn't fight the current — it masters it." |
| Warrior / Power | Direct, commanding | "The dragon doesn't ask for permission to breathe fire." |
| Balance / Healing | Reflective, grounded | "Light and dark don't fight. They complete each other." |
| Flow / Nature | Poetic, expansive | "The wave doesn't resist the ocean. It IS the ocean." |
| Kindness / Grace | Paradoxical, sharp | "Grace is the weapon they never see coming." |
| Mastery / Legacy | Timeless, philosophical | "The master doesn't rush the mountain. He becomes it." |
