# Lord Judah IG Viral Amplifier

## What This Does

Runs a Meta Engagement Ad on an **existing Instagram post** to inflate on-platform metrics (likes, comments, views). When engagement spikes, Instagram's algorithm treats the post as high-quality content and pushes it organically to non-followers — especially via the **Explore page**.

**Key difference from other ad strategies:**
- Includes **Instagram Explore** (highest discovery surface — non-followers find you here)
- Optimizes for **post engagement**, not video views or link clicks
- Works on any existing post — Reels, carousels, images
- Minimum $1/day — designed to always be running

## Step-by-Step Execution

### Step 1 — Create the Campaign

1. Go to **Meta Ads Manager** → business.facebook.com/adsmanager
2. Click **"+ Create"**
3. Objective: **Engagement** → Continue
4. Name: `LJ - [Song Title] - IG Amplify - [Date]`
   - Example: `LJ - Blessed and Grateful - IG Amplify - Jul26`
5. **Campaign Budget:** Daily budget — **$5/day** (minimum $1/day)
6. Click **Next**

### Step 2 — Configure the Ad Set

1. Name: `LJ - [Song Title] - Amplify Ad Set`
2. **Conversion location:** On your ad
3. **Engagement type:** Post engagement
4. **Performance goal:** Maximize engagement with a post
5. **Schedule:** Start = release date, End = 7–14 days later
6. **Audience:** Click **"Switch to original audience options"** → confirm **"Use original audience"**
7. Define audience:
   - Locations: United States + UK, Canada, Australia
   - Age: 18–45
   - Gender: All
   - Detailed targeting: Hip hop, conscious rap, Kendrick Lamar, J. Cole, Nas, Boom bap
   - OR use existing Custom/Lookalike audiences from previous campaigns
8. Click **Next**

### Step 3 — Set Placements (CRITICAL — Different From Other Skills)

1. Select **"Manual placements"** (NOT Advantage+)
2. **Turn OFF:** Facebook (all), Audience Network (all), Messenger (all)
3. **Keep ON — Instagram only (3 placements):**
   - Instagram Feed ✅
   - Instagram Explore ✅ ← **This is the key — non-followers discover you here**
   - Instagram Reels ✅
   - Everything else ❌ (Stories, Profile Feed, Search — all OFF)
4. Click **Next**

### Step 4 — Set Up the Ad

1. Name: `LJ - [Song Title] - Amplify Ad`
2. **Identity:** Select the Lord Judah Facebook Page + @lordjudah Instagram account
3. **Multi-advertiser ads:** Toggle **OFF**
4. **Ad setup:** Select **"Use existing post"**
5. Click **"Select post"**
6. Navigate to the **Instagram** tab in the pop-up
7. Select the **release day Reel** for the song
8. Click **Continue**
9. Confirm the correct post is showing in preview

### Step 5 — Publish

1. Click **"Review to publish"**
2. Confirm: correct post, correct placements (Feed + Explore + Reels only), Multi-advertiser OFF
3. Click **Publish**
