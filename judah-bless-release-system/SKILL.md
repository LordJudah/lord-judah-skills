# Judah Bless Ent — Content Release System

## Overview

A 26-task, 3-phase independent release framework built for Lord Judah / Judah Bless Ent. Generated by Judah Prime (mission prime-001, 2026-07-17). Use as the master operational template for every release.

**Full checklist:** See `references/release_checklist.md`

## Phase Summary

| Phase | Items | Window | Key Actions |
|---|---|---|---|
| Pre-Release | 11 tasks (1-11) | T-21 to T-1 | Master, BMI, art, distribution, Shopify, copy, schedule |
| Release Day | 6 tasks (12-17) | T-0 (12:01 AM-evening) | Go-live, posts, reel, story blitz, email, engagement |
| Post-Release | 9 tasks (18-26) | T+1 to T+30 | Thank you, lyric content, metrics, playlists, UGC, archive |

## Automation Split

**Fully automated:** Blotato scheduling, Mailchimp campaigns, DistroKid delivery, pre-save, Shopify digital delivery.
**Manual only:** BMI registration, final mix approval, cover art (initial), video production, playlist pitching, fan engagement.
**Hybrid:** Shopify product setup, social content creation, email copywriting.

## Platform Stack

| Task | Tool |
|---|---|
| Social scheduling | Blotato |
| Email campaigns | Mailchimp |
| Distribution | DistroKid / TuneCore |
| Store / merch | Shopify (admin.shopify.com/store/3dc356-d8) |
| Rights registration | BMI.com |
| Pre-save | DistroKid HyperFollow / Feature.fm |
| Playlist pitching | Spotify for Artists, SubmitHub, Groover |
| Analytics | Spotify for Artists, Blotato analytics, Shopify |

## Scalability

- **Single:** Use all phases as written. Total: 21 days prep + 30 days post.
- **EP/Album:** Extend pre-release to T-30. Add tracklist reveal (T-10), staggered singles, listening party at T-0.
- **Deluxe/Re-Release:** Compress pre-release to T-7. Focus on new content and re-engaging existing audience.

## Hub Integration

When executing a release via the Hub:
- Task **Judah Prime** to build caption copy bank, schedule Blotato posts, create Shopify product.
- Task **Hip Hop Pantheon** for cultural authenticity review of messaging and artist narrative.
- Hub executes Blotato scheduling, Mailchimp campaigns, and Shopify product creation directly via connectors (SHIP=yes required from Lord Judah).
