# Lord Judah Music Video Production

## Overview

Use this skill whenever Lord Judah wants to turn a **song**, **lyric sheet**, **concept**, **acapella section**, or **visual direction** into a structured music-video workflow. Treat the task as a real production pipeline rather than a single prompt.

The governing principle is simple: **separate creative direction from asset execution**. First define the song's visual meaning and section-by-section scene logic. Then lock the exact avatar, image source, audio section, and motion approach before rendering anything.

## Core Production Model

Approach every music-video request through five layers.

| Layer | Purpose |
|---|---|
| Concept layer | Determine the song's emotional, philosophical, and visual core |
| Structure layer | Break the song into intro, verse, hook, bridge, outro, or custom sections |
| Asset layer | Lock the exact avatar, photo, generated image, audio stem, and format |
| Scene layer | Assign the right visual mode to each section |
| Assembly layer | Organize the final output into a coherent video sequence |

Do not jump directly from lyrics to generation when the song contains narrative, symbolism, performance sections, or multiple emotional phases.

## Workflow Decision Tree

Use the following logic to choose the right production path.

| Situation | Action |
|---|---|
| User provides only a song concept | Develop a visual treatment before generating scenes |
| User provides concept plus lyrics | Build a section map and identify performance versus symbolic sections |
| User provides acapella or isolated vocals | Use those files for lip-sync-driven scenes where facial performance matters |
| User wants Lord Judah visibly performing | Use avatar-led or photo-based performance scenes |
| User wants cinematic symbolism or surreal transitions | Use generated-image-first or image-to-video scenes |
| User wants both performance and conceptual imagery | Use the hybrid music-video workflow |
| User uploads a specific photo to animate | Lock that file explicitly and treat it as the subject source |

If the request is creatively open-ended, choose the rest only after producing a concise internal treatment and asset preflight.

## Non-Negotiable Music-Video Preflight

Before generating scenes, lock the following production inputs.

| Field | Requirement |
|---|---|
| Song title | Working title or placeholder title |
| Video goal | Full music video, teaser, hook visualizer, verse clip, or promo cut |
| Section scope | Full song or named sections such as hook, verse 1, bridge, outro |
| Visual mode | Avatar performance, generated-image-to-video, uploaded-image animation, or hybrid |
| Subject source | Exact avatar label, photo file, or generated identity image |
| Voice or audio source | Exact acapella file, vocal stem, or text script |
| Aspect ratio | 9:16, 16:9, or 1:1 |
| Scene strategy | Performance-driven, narrative, symbolic, documentary, futuristic, or mixed |
| Motion style | Lip-sync close-up, walk-and-talk, dramatic push-in, parallax, cinematic pan, crowd energy, etc. |
| Output unit | Single finished video, scene pack, or shot list for later assembly |

If any item is ambiguous and materially affects the output, ask one concise clarifying question. If the user says to choose the rest, choose the remaining inputs and proceed.

## Asset Identity Rules

Treat all visual and audio sources as named production assets, not generic media.

### Avatar Rules

Use a named avatar registry whenever Lord Judah wants an on-camera performance. Prefer human-readable labels such as **Main Performance Avatar**, **Main Talking Avatar**, **Cinematic Performance Avatar**, or other approved names.

If the user says **use my avatar** and no specific avatar is named, use the saved default performance avatar for the requested type of video. If more than one avatar could fit, do not guess silently.

### Image Rules

Treat images as one of four classes.

| Image class | Meaning | Required handling |
|---|---|---|
| Generated scene image | Created during the current task for this song | Save the exact file and reuse that exact path for animation or revisions |
| Generated identity image | Created to depict Lord Judah in a stylized scene | Mark clearly that it is a generated version, not a direct avatar render |
| Uploaded photo | User-supplied file | Reference the exact filename or file path before animation |
| Library image | Previously approved still or design asset | Use only if clearly named or mapped in the registry |

Never refer vaguely to **the image** when multiple candidate images exist.

### Audio Rules

Treat audio as section-specific performance material.

| Audio type | Use |
|---|---|
| Full song | Use for high-level scene timing and emotional mapping |
| Acapella section | Use for lip-sync scenes and direct performance shots |
| Hook stem | Use for chorus performance scenes or recurring refrain visuals |
| Verse stem | Use for narrative performance scenes with section-specific expression |
| Ad-lib stem | Use for accent shots, transitions, and energy cutaways |

If multiple audio files are provided, label each one by section before production begins.

## Supported Music-Video Workflows

## 1. Concept-to-Treatment Workflow

Use this when the user provides a song theme, title, or concept but no detailed shot plan.

1. Identify the emotional core, message, and symbolic motifs.
2. Translate the concept into a short visual treatment.
3. Decide whether the video should feel performance-driven, cinematic, documentary, surreal, or hybrid.
4. Only after the treatment is clear should scene generation begin.

## 2. Lyrics-to-Scene Workflow

Use this when the user provides lyrics.

1. Break the lyrics into sections.
2. Identify the visual function of each section: performance, narrative, symbolism, transition, or crowd-energy release.
3. Highlight key bars or phrases that deserve literal or metaphorical imagery.
4. Build a scene map that follows the song's progression rather than assigning random visuals.

Read `references/scene-treatment-guide.md` when the song has multiple conceptual layers or when a formal scene treatment would improve quality.

## 3. Acapella-to-Lip-Sync Workflow

Use this when the user provides isolated vocals or requests scenes with visible mouth sync.

1. Identify the exact audio file and the exact song section it represents.
2. Decide whether the best subject is a HeyGen avatar, a stylized photo animation, or another performance method.
3. Use short, clearly bounded vocal segments for stronger lip-sync accuracy.
4. Match facial framing, camera distance, and emotional intensity to the delivery style.
5. If the scene is not truly lip synced, describe it honestly as performance-inspired rather than full sync.

Read `references/lip-sync-planning.md` whenever acapella stems or section-specific performance clips are part of the request.

## 4. Generate-Image-First Music-Video Workflow

Use this when the user wants cinematic scenes created first and animated after.

1. Generate still images for the chosen section or sections.
2. Save each image with a section-specific name.
3. Animate the exact saved stills.
4. Preserve the section-to-image mapping so revisions stay consistent.

This is especially useful for symbolic visuals, futuristic worlds, memory sequences, album-art-derived scenes, and surreal transitions.

## 5. Hybrid Performance Workflow

Use this when the music video should combine Lord Judah's visible performance with conceptual or cinematic inserts.

1. Lock the performance subject first.
2. Build the symbolic or cinematic inserts second.
3. Assign which sections are performance-led and which are environment-led.
4. Maintain consistent wardrobe, mood, and color logic across both modes.

This is the default workflow for most serious music-video requests because it balances artist presence with cinematic range.

## Scene Assignment Rules

Each song section should have a defined visual job.

| Section type | Preferred visual role |
|---|---|
| Intro | Establish world, mood, and visual thesis |
| Verse | Carry narrative, message, or lyrical detail |
| Hook | Deliver repeatable signature imagery and strongest performance identity |
| Bridge | Shift energy, scale, or perspective |
| Outro | Resolve the message or leave a final symbolic image |

Do not overload every bar with a new idea. Strong music videos usually repeat visual anchors while evolving atmosphere.

## Performance Strategy Rules

Choose performance style based on the music section, not just platform convenience.

| Performance mode | Best use |
|---|---|
| Direct-to-camera avatar performance | Hooks, declarations, teaching lines, and persuasive bars |
| Walk-and-talk simulation | Motivational, reflective, or movement-based statements |
| Lip-sync close-up | Acapella-led bars where mouth sync matters most |
| Cinematic half-body performance | Verses needing presence without full-body motion claims |
| Symbolic cutaway | Metaphoric or spiritual lines that should not be illustrated literally |

Be honest about motion limits. If the platform creates a simulated walk effect rather than a full-body walk cycle, report that clearly.

## Visual Language for Lord Judah

Default to visuals that align with Lord Judah's identity: **cinematic**, **intelligent**, **grounded in hip-hop culture**, **future-facing**, and **symbolically rich**. Favor urban texture, dramatic lighting, spiritual undertones, and elevated cultural presence over generic commercial imagery.

Use color and environment intentionally. Black, gold, deep purple, metallic accents, murals, studio spaces, city textures, silhouettes, and subtle AI-futurist elements generally fit the brand better than random glossy stock scenes.

## Quality-Control Rules

Before delivery, review the project at three levels.

| Check level | Standard |
|---|---|
| Creative integrity | Visuals match the song's message and emotional arc |
| Asset accuracy | Correct avatar, correct image, correct audio section, correct aspect ratio |
| Performance honesty | Lip sync, motion style, and scene realism are described accurately |

If revisions are needed, specify them precisely, such as **use the hook acapella instead of the verse stem**, **replace symbolic fire motif with city-light motif**, **make verse 1 more intimate**, or **use generated image B for the bridge sequence**.

| Field | Value |
|---|---|
| Song | Title or working title |
| Goal | Full video, teaser, hook clip, etc. |
| Sections | What part of the song is being used |
| Mode | Chosen workflow |
| Subject | Exact avatar, photo, or generated identity image |

| Motion | One sentence |

Use this summary to prevent asset mix-ups and keep revisions traceable.
