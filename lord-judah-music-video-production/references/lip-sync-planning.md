# Lip-Sync Planning

Use this reference whenever the user provides acapellas, isolated vocals, or asks for scenes that visibly match sung or spoken delivery.

## Core Rule

Lip sync works best when the production input is broken into **small, clearly labeled sections**. Avoid treating an entire song as one undifferentiated sync request when better results can be obtained by working section by section.

## Preferred Audio Inputs

| Input type | Priority | Why |
|---|---|---|
| Short acapella section | Highest | Best control over sync, expression, and shot design |
| Hook-only stem | High | Ideal for repeating chorus performance shots |
| Verse-only stem | High | Best for bars that need exact mouth movement |
| Full acapella | Medium | Good for planning, but often better when divided into sections |
| Mixed full song | Lower | Useful for concept timing, not always ideal for exact sync generation |

## File Labeling Rules

Before generation, label every file with a section identity.

| Example label | Meaning |
|---|---|
| hook_main.wav | Main chorus vocal |
| verse1_lead.wav | Lead vocal for verse 1 |
| bridge_phrase_a.wav | Bridge section first phrase |
| adlib_transition.wav | Accent vocal for transition shot |

If the user uploads multiple audio files without labels, assign clear working labels before building scenes.

## Scene-Type Matching

| Scene type | Best audio input |
|---|---|
| Performance close-up | Short hook or verse section |
| Medium performance shot | Verse or hook stem |
| Walk-and-talk performance | Spoken or rhythmically moderate section |
| Symbolic montage | Full song or no direct sync required |
| Cutaway transition | Ad-lib, echo, or instrumental section |

## Practical Guidance

Keep lip-sync shots strategically placed. The strongest workflow often uses exact sync for the hook, selected key bars, and emotionally important lines, while letting other scenes operate as cinematic montage or symbolic support.

## Honesty Standard

If a scene uses music-driven motion without accurate mouth matching, describe it as **performance-led** or **music-responsive**, not as exact lip sync.

## Revision Language

When a synced scene needs revision, specify the problem with production language.

| Problem | Revision note |
|---|---|
| Wrong vocal section | Use hook_main.wav instead of verse1_lead.wav |
| Weak facial energy | Increase performance intensity and closer framing |
| Sync feels loose | Shorten source segment and regenerate as a tighter close-up |
| Wrong identity source | Replace generated identity image with named avatar asset |
