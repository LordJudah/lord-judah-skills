# Scene Treatment Guide

Use this reference when a song concept or lyric sheet needs to be translated into a structured visual plan.

## Treatment Goal

A scene treatment should explain how the video evolves across the song, not just list random shots. The treatment should identify the **visual thesis**, the **section-to-section progression**, and the **repeatable anchor images** that hold the video together.

## Treatment Structure

| Section | What to define |
|---|---|
| Core idea | The central emotional or philosophical message of the song |
| Visual thesis | The one-sentence statement describing how that message should look on screen |
| Environment system | The main worlds, locations, or recurring spaces |
| Performance system | Where Lord Judah is seen performing versus implied symbolically |
| Symbol system | Recurring motifs such as crown, light, city, frequency, mirrors, silhouettes, murals, or future-tech overlays |
| Progression | How the video escalates, shifts, or resolves over time |

## Section Mapping Model

| Song section | Questions to answer |
|---|---|
| Intro | What visual world opens the piece? |
| Verse 1 | What narrative or point of view is introduced? |
| Hook | What signature image should return each time? |
| Verse 2 | What deepens or complicates the message? |
| Bridge | What emotional or visual pivot occurs? |
| Outro | What final statement or symbolic image remains? |

## Treatment Writing Rules

Write in concise paragraphs, not bloated prose. Keep each section specific enough to guide production. If the user only wants a quick execution path, compress the treatment into a short section map rather than a full creative document.

## Good Visual Anchors

Strong music videos usually repeat a few memorable visual anchors.

| Anchor type | Example |
|---|---|
| Performance anchor | Lord Judah in a high-contrast alley, studio, rooftop, or mural corridor |
| Symbolic anchor | Crown light, lion silhouette, fractured mirror, waveform aura |
| Location anchor | Subway platform, city rooftop, industrial corridor, classroom, gallery, stage |
| Color anchor | Black-gold contrast, deep purple atmosphere, metallic silver future glow |

## Common Mistakes

| Mistake | Correction |
|---|---|
| New visual concept every bar | Reuse anchor images and evolve them |
| Literal visual for every lyric | Mix literal, symbolic, and performance imagery |
| No difference between verses and hook | Give the hook the strongest recurring identity |
| Overly generic cinematic language | Tie every scene to the song's message and Lord Judah's brand DNA |
