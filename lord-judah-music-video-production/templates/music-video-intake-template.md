# Music Video Intake Template

Use this template to make future music-video requests precise and repeatable.

| Field | Fill in |
|---|---|
| Song title |  |
| Video goal | Full music video / teaser / hook clip / verse clip / promo visual |
| Concept | One paragraph describing the message, mood, and world |
| Lyrics | Full lyrics or the sections being used |
| Audio provided | Full song / acapella / hook stem / verse stem / ad-libs |
| Audio labels | Name each file by section |
| Subject mode | Avatar / uploaded photo / generated version of me / hybrid |
| Exact subject asset | Name the avatar, uploaded file, or image set |
| Aspect ratio | 9:16 / 16:9 / 1:1 |
| Duration target |  |
| Scene style | Performance / narrative / symbolic / futuristic / documentary / hybrid |
| Required shots | Any must-have scenes or moments |
| Style notes | Color palette, wardrobe, mood, references |
| Deliverable | One final video / scene pack / tests for review |
