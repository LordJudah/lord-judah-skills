# Shopify Product Description Template — LJB Course Launch Workflow

Use this HTML template for the `COURSE_DESCRIPTION_HTML` variable in `create_course_product.py`.
Replace all `{VARIABLES}` before use.

---

```html
<h2>{HOOK_HEADLINE}</h2>
<p>{COURSE_TITLE} is a {MODULE_COUNT}-module online course that {ONE_SENTENCE_DESCRIPTION}.</p>

<h3>What You'll Learn</h3>
<ul>
  <li><strong>Module 1 — {MODULE_1_TITLE}:</strong> {MODULE_1_DESCRIPTION}</li>
  <li><strong>Module 2 — {MODULE_2_TITLE}:</strong> {MODULE_2_DESCRIPTION}</li>
  <li><strong>Module 3 — {MODULE_3_TITLE}:</strong> {MODULE_3_DESCRIPTION}</li>
  <li><strong>Module 4 — {MODULE_4_TITLE}:</strong> {MODULE_4_DESCRIPTION}</li>
</ul>

<h3>Final Project</h3>
<p>{FINAL_PROJECT_DESCRIPTION}</p>

<h3>What's Included</h3>
<ul>
  <li>Video lessons for each module</li>
  <li>Creative exercises and writing prompts</li>
  <li>Lifetime access</li>
  <li>Certificate of completion</li>
</ul>

<p><em>"{CLOSING_QUOTE}"</em></p>
```
